# v0.8.3 로컬 릴리스 후보

공유 검증 소스 `109eb4dd`에서 버전 메타데이터와 릴리스 문서를 고정합니다. 공개 배포와 자동 업데이트 게시 여부는 별도이며, 이 문서는 서명·공증·설치 검증 완료를 대신하지 않습니다.

- Vox 기본 엔진을 유지하고 Windows Qwen3-TTS 0.6B와 Mac MLX Qwen을 명시적으로 선택할 수 있는 실험 엔진으로 추가합니다. 모델은 외부 설치이며 앱에 포함하지 않습니다.
- Dots 연결 안내와 저장 확인을 보강하고, 공식 터널 런타임과 호환되지 않는 로그 버퍼 옵션을 제거합니다.
- Dots 음성 준비 시간과 표시/재생 시간을 분리하고, 대화창 없이 설정에서 음성을 준비할 수 있습니다. 소유권·숨김·엔진 변경·취소 시 오래된 결과를 폐기합니다.
- Windows 모델 검증과 명시적 복구, 제한된 수치 진단을 보강합니다. 준비 성능을 품질이나 속도 우위로 단정하지 않습니다.

완료 시 worker를 해제하여 다음 출력에서 준비가 반복될 수 있습니다. 상주 TTL·수동 해제·참조 캐시·Windows native GGUF/CUDA 비교는 [후속 이슈 #32](https://github.com/ddol2ya/DAEMONLET/issues/32)로 넘깁니다. 이번 릴리스에는 해당 최적화를 넣지 않습니다.

Mac은 기존 정식 Developer ID와 Apple 공증 절차로 검증하며 Windows는 무서명입니다. 최종 산출물별 해시·검증·실제 설치 결과는 로컬 증거 문서에 기록합니다. 기존 사용자 설정·캐릭터·음성 모델·연결·보안 저장소는 설치 데이터와 분리해 보존합니다.
