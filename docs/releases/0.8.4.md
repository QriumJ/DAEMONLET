# v0.8.4 로컬 릴리스 후보

Windows 음성 준비와 캐릭터 음성 설정을 개선합니다. 공개 릴리스 전 검수 문서이며 최종 서명·공증·재배포 조건·설치 검증 결과는 산출물별 검증 기록에 따릅니다.

- Windows x64에서 Qwen 0.6B Base Q8 GGUF와 VoxCPM2 F16 GGUF를 주 음성 설정 경로로 제공합니다. 고정된 CUDA·Vulkan 실행 환경을 구분하며 기존 PyTorch 연결은 이전 방식 관리에서 유지합니다. 기존 엔진 선택과 연결을 자동 변경하지 않습니다.
- 음성 설정을 엔진 선택, 목소리 선택, 준비, 관리의 순서로 정리합니다. Qwen WAV 복제와 Vox 학습팩의 차이를 설명하고, Qwen 선택이 Vox의 학습 가중치를 적용한 것으로 표시되지 않게 합니다.
- Windows GGUF 실행 환경을 앱에 포함하고 사용자 선택에 따라 검증·추출합니다. Qwen 모델 쌍은 약 1.28GB, Vox 공개 모델 쌍은 약 5.07GB이며 모델은 별도 다운로드입니다. 앱 시작이나 엔진 선택만으로 모델을 받지 않습니다.
- 정상 출력 정리와 음성 실행기 해제를 구분하고, 준비된 실행기 유지·수동 해제·음소거 및 종료 시 정리를 보강합니다. 취소·엔진 변경·오래된 요청의 결과는 현재 출력으로 전달하지 않습니다.
- Mac Vox GGUF 준비에서 한 번의 검증 안에 중복되는 파일 해시 읽기를 줄입니다. 새 준비 요청의 전체 해시 검증과 변환 시 검증은 유지합니다.

Apple Silicon은 기존 Metal Vox GGUF와 MLX Qwen 경로를 유지합니다. Windows CUDA·Vulkan의 하드웨어별 검증 범위는 최종 후보 기록에 명시합니다. RTX4090 결과가 다른 NVIDIA·AMD·Intel GPU의 검증을 대신하지 않습니다. 기존 Vulkan 경로를 제거하지 않습니다.

캐릭터·학습팩·기준 WAV·외부 모델·앱 설정을 보존합니다. 관리의 모델 삭제는 앱이 받은 모델과 해당 다운로드 캐시에 한정되며 외부 모델과 개인 학습팩은 포함하지 않습니다. Mac은 정식 Developer ID 서명·Apple 공증 확인 후 배포하고 Windows는 무서명 배포 정책과 사용자별 업데이트 동의를 유지합니다. 자동 업데이트 확인은 기본적으로 꺼져 있으며 다운로드·설치·재시작에는 사용자의 선택이 필요합니다.
